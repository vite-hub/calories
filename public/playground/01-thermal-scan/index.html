Send the plate.Get the numbers.

How a photo becomes a saved meal

One message to the bot runs these five steps in order. The reply only says “saved” after step four has read the meal back from the database.

  1. Step 1

    You send the photo

    Send it to your private Telegram bot. Text and voice notes work too; voice goes through the transcribe Capability first.

    Only your user ID can talk to the bot.
  2. Step 2

    Items and grams

    The model names each item on the plate and estimates the edible weight.

    2 fried eggs100 g
    Sourdough toast60 g
    Half an avocado70 g
  3. Step 3

    Calories and protein

    Each item gets calories and protein, and the meal gets a confidence.

    Eggs196 kcal13.6 g
    Toast150 kcal5.4 g
    Avocado112 kcal1.4 g
    Total458 kcal20.4 g
    Confidencemedium
  4. Step 4

    Saved to the database

    The Agent writes the meal with the db Capability, then reads it back.

    • Items and totals written
    • Photo stored privately
    • Meal read back
    • Allowed to say “saved”
  5. Step 5

    The reply

    The breakdown comes back with a dashboard link and the cost of that one reply.

    Saved breakfast. 458 kcal and 20.4 g protein, confidence medium.

    Dashboard: calories.example.com

    $0.0021

Reply to fix it, ask to read it

Reply to a meal with that was 2 eggs, not 3 to correct it, or ask to remove it. Ask how much protein this week? and the Agent answers from your journal.

A read-only dashboard

Two rings show the day’s calories and protein against your goals, above a meal history with photo previews. Previews are resized to 768 px and stripped of camera metadata; originals stay private.

It’s yours to change

The Agent is one file, server/agents/calories/agent.ts, about 100 lines, plus a 28-line prompt. ViteHub gives it the same database and Blob storage API on every host, so each swap below is one line.

Host it yourself

Pick one of five deployment presets in nuxt.config.ts.

// nuxt.config.ts
vitehub: { preset: "node" }

Swap the channel

Telegram is the example. Declare Discord, Slack, Teams, GitHub, HTTP, web chat or your own adapter in the same place.

channels: {
  telegram: telegram({ allowedUserIds, botToken }),
}

Swap the model

The default is a GLM model through OpenRouter. Any AI SDK model works, including GPT, Claude and Gemini.

driver: { model: () => openRouter("z-ai/glm-5.3-flashx") }

Grant only what it needs

The Agent gets these four Capabilities and nothing else. Add your own the same way.

capabilities: [
  blob({ mode: "write" }), db({ mode: "write" }),
  transcribe({ execute }), usage(),
]

Clone it and run it

You need an OpenRouter key, a Telegram bot token and your Telegram user ID.

Clone the template Read the ViteHub docs See the host support matrix 
git clone https://github.com/vite-hub/calories.git
cd calories && pnpm install && cp .env.example .env
# add OPENROUTER_API_KEY, TELEGRAM_TOKEN, TELEGRAM_ALLOWED_USER_ID
pnpm db:migrate && pnpm dev

Requires Node.js 24.15+ and pnpm 10.

Estimates can be wrong. Calories is an experiment, not medical or dietary advice.
