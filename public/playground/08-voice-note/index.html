Fix it the way you logged it

Reply to a meal with a voice note or a line of text, like “actually it was one egg”, and the Agent updates that meal and its totals. Reply “remove this” to delete it.

You can also ask about your journal. The answer comes from the meals saved in the database. Hold the big button at the top a second time to hear the correction.

One Agent file on top of ViteHub

The whole Agent is server/agents/calories/agent.ts, about 100 lines, plus a 28-line prompt. ViteHub gives it a channel, a model and a short list of Capabilities, and runs it on the host you pick.

// server/agents/calories/agent.ts
import { defineAgent } from "vite-hub/agent";
import { blob, db, transcribe, usage } from "vite-hub/agent/capabilities";
import { telegram } from "vite-hub/agent/channels";

export default defineAgent({
  capabilities: [blob({ mode: "write" }), db({ mode: "write" }),
    transcribe({ execute }), usage()],
  channels: {
    telegram: telegram({
      allowedUserIds: () => [env.telegram.allowedUserId],
      botToken: () => env.telegram.botToken,
    }),
  },
  driver: { model: () => openRouter("z-ai/glm-5.3-flashx") },
});

Four Capabilities

blob for photos, db for meals, transcribe for voice notes, usage for the cost line. The Agent gets these four and nothing else. Add your own the same way.

Any channel

Telegram is one entry in channels. Replace it with Discord, Slack, Teams, GitHub, HTTP, web chat or your own adapter. Only one allowed user ID can talk to this bot.

Any model

The default is a GLM model through OpenRouter. Any AI SDK model fits in driver, including GPT, Claude and Gemini.

Any host, including yours

Five presets, one line in nuxt.config.ts.

vitehub: { preset: "cloudflare" }

Meals in D1, photos in R2.

Start with your own breakfast

Clone the template, add three keys, and send your bot the first meal. It runs locally with pnpm dev.

git clone https://github.com/vite-hub/calories.git
cd calories && pnpm install && cp .env.example .env
# add OPENROUTER_API_KEY, TELEGRAM_TOKEN, TELEGRAM_ALLOWED_USER_ID
pnpm db:migrate && pnpm dev
Clone the template Read the ViteHub docs

Needs Node.js 24.15 or newer and pnpm 10. A local Console at /_vitehub shows recent Agent sessions.

Estimates can be wrong. Calories is an experiment, not medical or dietary advice. Values on this page are examples.
