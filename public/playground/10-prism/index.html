One meal in,everything out.

Calories is an open-source ViteHub Agent template. Send a private Telegram bot a photo, a voice note, or a line of text about a meal. It names each item, estimates grams, calories, and protein, and saves the meal.

You“2 fried eggs, sourdough toast, half an avocado”

You send 2 fried eggs, sourdough toast, half an avocado. The light comes back as seven parts of the reply.

  1. Itemseggs, sourdough toast, avocado
  2. Grams100 g, 60 g, 70 g edible weight
  3. Calories458 kcal for the meal
  4. Protein20.4 g, confidence medium
  5. Saveda row in meals, read back
  6. Dashboardcalories.example.com
  7. Cost$0.0021 for this reply

A food journal you fill from a chat

Calories is a working Agent you fork and run on your own accounts. It answers one allowed Telegram user and keeps every meal in a database you control.

Photo, voice, or text
Photograph the plate, say “two eggs and toast” in a voice note, or type it. Voice notes are transcribed through the transcribe Capability first, with Voxtral via OpenRouter in the template.
Replies you can correct
Reply to a logged meal with “that was 2 eggs, not 3” and the saved meal changes. Remove one the same way.
Questions about your week
Ask “how much protein this week?” and the Agent answers from the meals it saved.
A dashboard only you read
A read-only Nuxt page with today’s totals and your meal history. Photo previews are resized to 768 px and stripped of camera metadata. Originals stay private.

The light, read back as a reply

Each band in the prism at the top is a line of the message the bot sends. The underlines carry the same colors.

Logged means writtenThe Agent says a meal is saved only after the database write succeeded and the row read back.

The last line is the billThe model cost of that one reply, from the usage() Capability. The values here are examples.

Estimates can be wrong. Calories is an experiment, not medical or dietary advice.

One agent file in, any channel or host out

The whole Agent is server/agents/calories/agent.ts, about 100 lines, plus a 28-line instructions.md prompt. ViteHub makes the channel and the host each a one-line change.

    Any model
    The template drives the Agent with a GLM model via OpenRouter: openRouter("z-ai/glm-5.3-flashx"). Any AI SDK model fits the same slot, including GPT, Claude, and Gemini.
    
    
    Your own box
    The node preset runs on a machine, VPS, or container you own. Meals live in a SQLite file on that disk, and photos sit next to it.
    
    
    Only what you grant
    The Agent gets four Capabilities, blob, db, transcribe, and usage, and nothing else. A local Console at /_vitehub shows its recent sessions.
    
  
    

    


    
  
    Clone it and send your first meal
    
  
    Four commands, three keys in .env, then text the bot what you had for lunch.
    
  
    git clone https://github.com/vite-hub/calories.git
cd calories && pnpm install && cp .env.example .env
# add OPENROUTER_API_KEY, TELEGRAM_TOKEN, TELEGRAM_ALLOWED_USER_ID
pnpm db:migrate && pnpm dev
    
  
    Requires Node.js 24.15+ and pnpm 10. Stack: ViteHub, Nuxt, Vue, Nuxt UI, AI SDK, OpenRouter, Drizzle, and Nitro.
