Every meal gets a receipt.

Send a meal to your own Telegram bot as a photo, a voice note, or a line of text. It names each item, estimates grams, calories, and protein, saves the meal, and tells you what the reply cost.

Calories is an MIT-licensed ViteHub template. Fork it, then run it on Cloudflare, Vercel, Netlify, Deno, or a server you own.

SEE YOU AT LUNCH

The template, itemized

Calories is a working example meant to be forked. The whole Agent is one file of about 100 lines and a 28-line prompt, so you can read all of it before lunch.

THE TEMPLATE
vite-hub/calories, branch main
QTYITEM
1xagent.ts~100 lines
server/agents/calories/
1xinstructions.md28 lines
4xCapabilities
blob, db, transcribe, usage

The Agent gets the four Capabilities it lists and nothing else. Blob files hold photos, the database holds meals, transcribe turns voice notes into text with Voxtral, and usage reports the cost of each reply.

1xChannel (Telegram)
swap any time
1xModel (GLM, OpenRouter)
any AI SDK model
1xDashboard (Nuxt)
read-only
1xConsole at /_vitehub
recent sessions, read-only

Swap Telegram for Discord, Slack, Teams, GitHub, HTTP, web chat, or your own adapter. Swap GLM for GPT, Claude, Gemini, or any other AI SDK model.

Exchanges take one line

ViteHub gives the Agent the same database, Blob storage, and env API on every host. Moving from Cloudflare to your own server is one edit in nuxt.config.ts.

The same API covers KV, auth, queues, workflows, schedules, and email when the fork needs them.

On the node preset your meals live in a SQLite file on a disk you own. Run it on a VPS, a box under the desk, or in a container.
