Correct a meal by replying to it.

Reply to any saved meal with what was wrong and the Agent updates that meal. Ask about your journal and it answers from the database.

A read-only Nuxt dashboard shows the day against your goals as two rings, and every meal with its photo preview. Previews are resized to 768 px and stripped of camera metadata. Originals stay private.

how much protein this week?

Clone it, add three keys, run it.

Everything the Agent does lives in server/agents/calories/agent.ts, about 100 lines, and a 28-line prompt. Fork it and edit the lines you want different.

Needs Node.js 24.15+ and pnpm 10. Recent Agent sessions show up in the local Console at /_vitehub.

Clone the template Read the ViteHub docs
Terminal
$ git clone https://github.com/vite-hub/calories.git
$ cd calories && pnpm install && cp .env.example .env
# add OPENROUTER_API_KEY, TELEGRAM_TOKEN,
# and TELEGRAM_ALLOWED_USER_ID to .env
$ pnpm db:migrate && pnpm dev

Calories and protein are model estimates and can be wrong. This template is an experiment, not medical or dietary advice.
