Calories a ViteHub Agent template, MIT license

Photograph your breakfast. Get the label back.

Send a private Telegram bot your meal as text, a photo, or a voice note. It names each item, estimates grams, calories, and protein, saves the meal to your database, and replies with the breakdown. You clone the whole thing, so the channel, the model, and the host are yours to change.

ViteHub gives each swap one place to live. The host is one line in nuxt.config.ts, vitehub: { preset: "cloudflare" }. The channel, the model, and the Capabilities are entries in agent.ts.

Calorie and protein figures are estimates and can be wrong. Calories is an experiment, not medical or dietary advice.

Ingredients: ViteHub (portable Agents for Vite, built on server primitives), Nuxt, Vue, VueUse, Nuxt UI, AI SDK, OpenRouter (GLM for chat and vision, Voxtral for voice), Drizzle, Nitro.

Storage: keep meals in a database you own. The cloudflare preset uses D1 with photos in R2. The node preset keeps them in a SQLite file on your disk.

Directions: clone and install, copy .env.example to .env and add three keys, migrate, then start the dev server. Requires Node.js 24.15+ and pnpm 10.

git clone https://github.com/vite-hub/calories.git
cd calories && pnpm install && cp .env.example .env
# add OPENROUTER_API_KEY, TELEGRAM_TOKEN, TELEGRAM_ALLOWED_USER_ID
pnpm db:migrate && pnpm dev
