Calories is an experiment. The calorie and protein numbers are model estimates and can be wrong, so treat them as a journal, not medical or dietary advice.

What it's built on

Every package below is in package.json. The agent file imports three of them: vite-hub, ai, and the OpenRouter provider.

vite-hub
ViteHub: the agent, its channel and Capabilities, plus database and Blob storage with the same API on every preset.
nuxt with vue
The read-only dashboard: daily calories and protein as two rings against your goals, and meal history with photo previews.
@nuxt/ui, @vueuse/nuxt
Components and composables for the dashboard.
ai
AI SDK. The voice-note transcription in agent.ts is one generateText call.
@openrouter/ai-sdk-provider
One OpenRouter key serves the chat model and Voxtral for transcription.
drizzle-orm
The meals table schema and the photo route's query.
nitro
The server runtime that each preset builds for.

From clone to a running dev server
git clone https://github.com/vite-hub/calories.git
cd calories && pnpm install && cp .env.example .env
# add OPENROUTER_API_KEY, TELEGRAM_TOKEN, TELEGRAM_ALLOWED_USER_ID
pnpm db:migrate && pnpm dev

Requires Node.js 24.15+ and pnpm 10. The template is MIT licensed, so the fork is yours.
