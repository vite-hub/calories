From a photo to two numbers

Calories is an open-source ViteHub Agent you fork and run yourself. Send your Telegram bot a meal as a photo, a sentence, or a voice note. It saves the meal to your database, then replies with calories and protein.

It names each item and estimates its weight

From the photo, the model lists two fried eggs, a slice of sourdough toast, and half an avocado, then estimates the edible grams of each.

Then it adds up the meal

Calories and protein per item, a total, and a confidence rating: medium for this plate. The bot says the meal is saved only after the database write is read back.

And rings it on your dashboard

A read-only Nuxt dashboard draws today's calories and protein against your goals, here 2,200 kcal and 140 g. Meal history sits below with resized photo previews. Originals stay private.

The answer comes back in the same chat

Each item with its grams, calories, and protein, then the meal total and a confidence rating. The last lines link to your dashboard and show what the model charged for that one reply.

Reply to a meal to correct or remove it. Ask "how much protein this week?" and it answers from your journal. Values on this page are examples.

Keep the meal logic and swap the rest

Telegram, a GLM model, and Cloudflare are this template's picks. ViteHub makes each one a single line, so your fork can pick differently.

Any channel

Telegram is declared in the Agent's channels. Discord, Slack, Teams, GitHub, HTTP, web chat, or your own adapter go in the same object.

channels: { telegram: telegram({ ... }) }

Any host

Five presets: cloudflare, vercel, netlify, deno, and node. The node preset runs on your own box, VPS, or container, and your meals live in a SQLite file you own.

vitehub: { preset: "node" }

Any model

Any AI SDK model can drive the Agent. The default is GLM through OpenRouter. GPT, Claude, and Gemini plug into the same line.

driver: { model: () => openRouter("z-ai/glm-5.3-flashx") }

Check the host support matrix

The whole Agent is one file

About 100 lines in agent.ts, with a 28-line prompt beside it. It is granted four Capabilities, blob, db, transcribe, and usage, and gets nothing else.

Voice notes go through transcribe, which uses Voxtral via OpenRouter. The cost line in every reply comes from usage.

server/agents/calories/agent.ts (excerpt)import { defineAgent } from "vite-hub/agent";
import { blob, db, transcribe, usage } from "vite-hub/agent/capabilities";
import { telegram } from "vite-hub/agent/channels";

export default defineAgent({
  capabilities: [
    blob({ mode: "write" }),
    db({ mode: "write" }),
    transcribe({ execute }),
    usage(),
  ],
  channels: {
    telegram: telegram({
      allowedUserIds: () => [env.telegram.allowedUserId],
      botToken: () => env.telegram.botToken,
    }),
  },
  driver: { model: () => openRouter("z-ai/glm-5.3-flashx") },
});

Clone it and send your bot breakfast

You need Node.js 24.15 or newer, pnpm 10, an OpenRouter API key, and a Telegram bot token. Only the user ID you allow can talk to the bot.

Terminalgit clone https://github.com/vite-hub/calories.git
cd calories && pnpm install && cp .env.example .env
# add OPENROUTER_API_KEY, TELEGRAM_TOKEN, TELEGRAM_ALLOWED_USER_ID
pnpm db:migrate && pnpm dev
