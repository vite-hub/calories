What happens to a meal

Every channel above runs the same steps in the same Agent.

  1. It arrives

    A photo, a line of text, or a voice note, from the one user ID allowed to talk to the bot. The transcribe Capability turns voice into text, with Voxtral via OpenRouter in the template.

  2. Items and grams

    The model names each thing on the plate and estimates its edible weight in grams.

  3. Calories, protein, confidence

    It estimates calories and protein per item, plus one confidence for the whole meal.

  4. Saved, then read back

    The meal goes into the database. The Agent says it saved the meal only after the write succeeded and it read the row back.

  5. The reply

    You get the breakdown, a link to your dashboard, and what that one reply cost in model usage, from the usage() Capability.

Reply to a meal to fix it, that was 2 eggs, not 3, or ask about your journal, how much protein this week?

Keep your meals on a box you own, or on any host

ViteHub builds the same codebase for five deployment presets. You pick one in nuxt.config.ts. With node, the app runs on your own machine, a VPS, or a container, and your meals live in a SQLite file you can copy, back up, or delete.

Swap the model in the driver

The template sends photos and text to a GLM model through OpenRouter. The driver takes any AI SDK model, so GPT, Claude, Gemini, or another provider's model goes in the same place. A coding agent such as Codex or Claude Code can drive it too, and so can plain application code.

The Agent can use only the Capabilities you grant it. Calories grants four.

  • blobstores meal photos
  • dbwrites and reads meals
  • transcribeturns voice notes into text
  • usagereports the cost of each reply
server/agents/calories/agent.tsthe driver
export default defineAgent({  capabilities: [    blob({ mode: "write" }), db({ mode: "write" }),    transcribe({ execute }), usage(),  ],  channels: { telegram: telegram({ ... }) },  driver: {    model: () => openRouter("z-ai/glm-5.3-flashx"),  },});

The whole Agent is this one file, about 100 lines, plus a 28-line instructions.md prompt.

Fork it, point it at your own bot token, and keep the parts you like. The template is MIT licensed.

git clone https://github.com/vite-hub/calories.git
cd calories && pnpm install && cp .env.example .env
# add OPENROUTER_API_KEY, TELEGRAM_TOKEN, TELEGRAM_ALLOWED_USER_ID
pnpm db:migrate && pnpm dev

Requires Node.js 24.15+ and pnpm 10. A local Console at /_vitehub shows recent Agent sessions, read-only.
